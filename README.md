# Modelo-predictivo-para-desplazamiento-interno-por-desastres-naturales
Proyecto de analítica predictiva para estimar el riesgo de eventos climáticos y su impacto potencial en el desplazamiento interno municipal en Colombia. Integra datos climáticos, ambientales, territoriales y socioeconómicos para anticipar escenarios de afectación y apoyar la gestión del riesgo de desastres.
